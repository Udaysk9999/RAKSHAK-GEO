# RAKSHAK-GEO AI DEVELOPMENT RULES

Before doing any work:

1. Read this file.
2. Read docs/PROJECT_SPEC.md
3. Read docs/ARCHITECTURE.md
4. Read docs/CURRENT_STATE.md
5. Read docs/TASK_BOARD.md
6. Inspect the existing code.
7. Never assume a feature is missing until you inspect the repository.

Rules:

- Do not rewrite working systems unnecessarily.
- Do not change architecture without documenting it.
- Do not change API contracts without updating API_CONTRACT.md.
- Do not invent data.
- Synthetic disaster resources must be labelled DEMO DATA.
- Do not add unnecessary technologies.
- Do not remove another developer's work.
- Keep existing functionality working.
- Run appropriate tests/builds before finishing.
- Update CURRENT_STATE.md after completing work.
- Update TASK_BOARD.md after completing work.
- Record important architectural decisions in DECISIONS.md.
